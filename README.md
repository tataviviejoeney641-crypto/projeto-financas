# Projeto Finanças

Aplicativo para gerenciamento de despesas pessoais e insights financeiros.

Descrição
- Interface mobile/web construída com React/Expo e Tailwind/nativewind.
- Backend leve com TRPC e Drizzle para modelagem/queries.
- Funcionalidades: criar/editar/despesas, categorias, relatórios e autenticação via OAuth.

Tecnologias
- React / Expo
- TypeScript
- Tailwind / NativeWind
- TRPC
- Drizzle (migrations/schema)
- Node.js (server)

Como rodar (rápido)
1. Instale dependências: `pnpm install` (ou `npm install`)
2. Configure variáveis de ambiente seguindo `scripts/load-env.js` se necessário
3. Rodar em desenvolvimento: `pnpm start` ou `expo start`

Contribuição
